# Multi speciality Medical centre management system — Screenshots

This folder contains screenshots demonstrating the interface and functionality of the Clinic Management System.

## Screenshots Included

* **Login Page:** Shows the clinic application login interface.
* **Admin Dashboard:** Displays the administration module.
* **Receptionist Dashboard:** Demonstrates patient and appointment management.
* **Doctor Dashboard:** Shows appointment and consultation options.
* **Pharmacist Dashboard:** Demonstrates medicine inventory and pharmacy operations.
* **Lab Technician Dashboard:** Shows laboratory test and report management.
* **Consultation Page:** Demonstrates the doctor consultation interface.

These screenshots illustrate the application's role-based modules and clinic management workflows.

## Technologies Used

* React
* JavaScript
* Bootstrap 5
* Django REST Framework
* JWT Authentication
* SQLite
